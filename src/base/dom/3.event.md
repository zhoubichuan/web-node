# 文件

## 1.获取目录下列表

::: demo

```vue
<template>
  <div class="fs-box">
     <input type="text" v-model="path" />
     <input type="text" v-model="count" />
    <button @click="handleList">获取根目录</button>
    根目录：{{fold}}
  </div>
</template>
<script>
export default {
  data() {
    return {
      fold: '',
      path: '/Users/zhoubichuan/',
      foldName:'my-image',
      count:6
    }
  },
  mounted() {
    // this.handleList()
  },
  methods: {
    async handleList(){
      const res = await this.$api.file({ type: 'move', path: this.path ,foldName:[this.foldName],count:this.count})
      if (!res) return
      this.fold = res
    }
  }
}
</script>
```
