# 目录

## 1.根目录

::: demo

```vue
<template>
  <div class="fs-box">
    <button @click="handleList">获取根目录</button>
    根目录：{{fold}}
  </div>
</template>
<script>
export default {
  data() {
    return {
      fold: '',
    }
  },
  mounted() {
    // this.handleList()
  },
  methods: {
    async handleList(){
      const res = await this.$api.file({ type: 'read', path: '' })
      if (!res) return
      this.fold = res
    }
  }
}
</script>
```

## 2.当前目录

::: demo

```vue
<template>
  <div class="fs-box">
    <input type="text" v-model="path"  style="width: calc(100% - 100px);" />
    <button @click="handleList">获取指定目录</button>
    当前目录：{{fold}}
  </div>
</template>
<script>
export default {
  data() {
    return {
      fold: '',
      path: ''
    }
  },
  mounted() {
    // this.handleList()
    this.path = localStorage.getItem('path')
  },
  methods: {
    async handleList(){
      const res = await this.$api.file({ type: 'read', path: this.path })
      if (!res) return
      this.fold = res
    }
  }
}
</script>
```

## 3.全部文件列表

::: demo

```vue
<template>
  <div class="fs-box">
     <input type="text" v-model="path"  style="width: calc(100% - 100px);" />
     <input type="text" v-model="foldName"  style="width: calc(100% - 100px);" />
    <button @click="handleList">全部文件列表</button>
    列表：{{fold}}
  </div>
</template>
<script>
export default {
  data() {
    return {
      fold: '',
      path: '',
      foldName:[]
    }
  },
  mounted() {
    // this.handleList()
     this.path = localStorage.getItem('path')
       localStorage.getItem('foldName')&& this.foldName.splice(0,this.foldName.length,...localStorage.getItem('foldName').split(','))
  },
  methods: {
    async handleList(){
      const res = await this.$api.file({ type: 'read', path: this.path ,foldName:this.foldName})
      if (!res) return
      this.fold = res
    }
  }
}
</script>
```

## 8.替换

::: demo

```vue
<template>
  <div class="fs-box">
    目录地址：<textarea  v-model="oldPath"  style="width: calc(100% - 100px);" />
    目录地址：<textarea  v-model="newPaht"  style="width: calc(100% - 100px);" />
    <button @click="handleList(foldName)">目录列表</button>
    目录列表：{{fold}}
  </div>
</template>
<script>
export default {
  data() {
    return {
      oldPath: '',
      newPaht: '',
    }
  },
  mounted() {
     this.path = localStorage.getItem('path')
  },
  methods: {
    async handleList(foldName){
      const res = await this.$api.file({ type: 'replace',oldPath:JSON.parse(oldPath),newPaht:JSON.parse(newPaht)})
      if (!res) return
      this.fold = res
    }
  }
}
</script>
```
