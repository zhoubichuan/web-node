# 目录

## 1.获取根目录

::: demo

```vue
<template>
  <div class="fs-box">
    <button @click="handleList">获取根目录</button>
    根目录：{{fold}}
  </div>
</template>
<script>
export default {
  data() {
    return {
      fold: '',
    }
  },
  mounted() {
    // this.handleList()
  },
  methods: {
    async handleList(){
      const res = await this.$api.file({ type: 'read', path: '' })
      if (!res) return
      this.fold = res
    }
  }
}
</script>
```

## 2.获取当前目录

::: demo

```vue
<template>
  <div class="fs-box">
    <input type="text" v-model="path"  style="width: calc(100% - 100px);" />
    <button @click="handleList">获取指定目录</button>
    根目录：{{fold}}
  </div>
</template>
<script>
export default {
  data() {
    return {
      fold: '',
      path: ''
    }
  },
  mounted() {
    // this.handleList()
    this.path = localstorage.getItem('path')
  },
  methods: {
    async handleList(){
      const res = await this.$api.file({ type: 'read', path: this.path })
      if (!res) return
      this.fold = res
    }
  }
}
</script>
```

## 5.获取目录全部文件内容

::: demo

```vue
<template>
  <div class="fs-box">
     <input type="text" v-model="path"  style="width: calc(100% - 100px);" />
     <input type="text" v-model="fileType" style="width: calc(100% - 100px);" />
    <button @click="handleList">获取根目录</button>
    根目录：{{fold}}
  </div>
</template>
<script>
export default {
  data() {
    return {
      fold: '',
      path: '',
      foldName:'my-image',
      fileType:'JPG',
      fileName:'1'
    }
  },
  mounted() {
    // this.handleList()
     this.path = localstorage.getItem('path')
  },
  methods: {
    async handleList(){
      const res = await this.$api.file({ type: 'read', path: this.path ,foldName:[this.foldName],fileType:[this.fileType],fileName:[{name:this.fileName}]})
      if (!res) return
      this.fold = res
    }
  }
}
</script>
```
